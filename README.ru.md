# pixel-diet

[![tests](https://github.com/slowpoke-flex/pixel-diet/actions/workflows/tests.yml/badge.svg)](https://github.com/slowpoke-flex/pixel-diet/actions/workflows/tests.yml)

**Большая часть скриншота — не информация.** Картинка 1920×1080 стоит визуальной модели примерно 2 765
image-токенов, и пустые поля, обои и шум компрессии стоят столько же, сколько кнопка, о которой вы спросили.

`pixel-diet` — небольшая библиотека и CLI: она обрезает, масштабирует и перекодирует изображение **до** того,
как оно попадёт в GPT-4o, Claude, Gemini или локальный Qwen-VL. Вместо пятнадцати порогов — именованные пресеты.
Тот же пакет превращает сравнение картинок в числа, чтобы агент вообще не смотрел на изображение, когда метрики
достаточно.

Разрабатывает **Mind Space Studio**. Лицензия MIT.

## Что экономится (измерено, а не обещано)

Пять синтетических входов из `examples/shrink_demo.py`, замер на этом ноутбуке
(Windows 11, Python 3.14, Pillow 13.0.0, 2026-10-26):

| Вход | Пресет | Пиксели | Байты | Оценка image-токенов |
|---|---|---|---:|---:|
| плоский UI с рамкой | `ui-agent` | 1920×1080 → 1280×678 | 9 811 → 8 152 (−16.9%) | 2 765 → 1 158 (**2.39×**) |
| скриншот рабочего стола | `ui-agent` | 1920×1080 → 1280×720 | 2 180 496 → 9 854 (−99.5%) | 2 765 → 1 229 (**2.25×**) |
| документ A4 | `ocr-document` | 1654×2339 → 800×1024 | 16 987 → 3 714 (−78.1%) | 5 159 → 1 093 (**4.72×**) |
| игровой спрайт | `game-sprite` | 512×512 → 225×289 | 1 865 → 120 (−93.6%) | 350 → 87 (**4.02×**) |
| кадр с камеры | `edge-fast` | 1600×900 → 768×432 | 14 852 → 3 208 (−78.4%) | 1 920 → 443 (**4.33×**) |

Повторить: `python examples/shrink_demo.py`

Читайте таблицу честно:

- **Байты настоящие**, это размеры файлов на этой машине. **Image-токены — оценка** по формуле
  `ceil(ширина × высота / 750)`, которую публикует Anthropic. Реальный счёт зависит ещё и от модели,
  провайдера и остального промпта.
- Входы синтетические, это не скриншоты клиентов. Строка с плоским UI — слабый случай: PNG из плоских цветов
  и так маленький, поэтому по **байтам** выигрыш почти нулевой, а по **токенам** — те же 2.4×. Выигрыш по трафику
  появляется на фотографических скриншотах (строка «рабочий стол»).
- Здесь нет обещания «модель отвечает идентично». Уменьшение может стереть подпись в 6 px. Проверяйте на своей задаче.

## Установка

Имя в PyPI зарезервировано под первый релиз; пока ставьте из репозитория:

```bash
git clone https://github.com/slowpoke-flex/pixel-diet.git
cd pixel-diet
python -m pip install -e .
```

Нужен Python ≥ 3.10, зависимости — только `numpy` и `Pillow`. Без компиляторов, OpenCV и весов моделей.

## Использование

```python
from pixel_diet import optimize_for_llm, optimize_bytes

uri = optimize_for_llm("raw_screenshot.png", preset="ui-agent")   # data:image/webp;base64,...
clean = optimize_bytes(raw_bytes, preset="ocr-document", max_dimension=1024)
```

`optimize()` принимает путь, `BytesIO`, изображение PIL или массив numpy и возвращает `Result` с полями
`data`, `width`, `height`, `saved_pct`, `tokens_before`, `tokens_after`, `token_ratio` и `.data_uri`.

```bash
pixel-diet shrink screenshot.png -o slim.webp --preset ui-agent
pixel-diet shrink ./invoices -o ./clean --preset ocr-document --json report.json
cat shot.png | pixel-diet shrink - -o - --preset ui-agent > slim.webp
```

`--max-dimension`, `--format webp|png|jpeg`, `--quality`, `--no-trim` переопределяют пресет.

### Пресеты

| Пресет | Что делает | Для чего |
|---|---|---|
| `ui-agent` | обрезает рамку цвета угла, длинная сторона ≤ 1280 px, WebP q80 | браузерная автоматизация, RPA, UI-агенты |
| `ocr-document` | обрезает ровные поля, градации серого, автоконтраст, ≤ 1024 px, WebP q85 | чеки, счета, сканы |
| `game-sprite` | обрезка по alpha-bbox, lossless WebP, без размытия краёв | 2D-спрайты, тайлсеты, иконки |
| `edge-fast` | билинейное уменьшение до 768 px, WebP q65 | камеры, дроны, слабый канал |

### Две вещи, которые кусаются

1. **Координаты.** Если агент кликает по (x, y), прочитанным с уменьшенной картинки, их нужно вернуть:
   `x * source_width / width`, так же для y. Если нужен исходный кадр — `--no-trim`.
2. **Мелкий текст.** Уменьшение может стереть подписи 6–8 px. `ocr-document` сохраняет контраст, но всё равно
   ограничивает 1024 px; когда важнее читаемость, поднимите `--max-dimension`.

## Сначала проверьте, потом доверяйте

Уменьшение по определению lossy. Честный цикл: уменьшить, прогнать задачу, сравнить с полноразмерным прогоном.
Вторая половина пакета делает это сравнение числами:

```bash
pixel-diet diff full.png shrunk.png --brief
pixel-diet mask pred.png gt.png --classes 1
pixel-diet depth pred.npy gt.npy
```

## Чем это не является

- Не модель, не датасет и не лидерборд.
- Не CDN, не хостинг картинок и не конвертер для архива.
- Не решает, «одинаковы ли» две картинки для вашей задачи; он даёт числа, решение остаётся за вами.
