# GitHub topics (pick up to 20)

GitHub allows 20 topics per repository. Copy these into **Settings → Topics**:

```text
computer-vision
image-evaluation
image-diff
psnr
ssim
segmentation
iou
dice
depth-estimation
object-detection
optical-flow
ai-agents
claude
codex
cursor
mcp
python
cli
quality-assurance
reproducibility
```

Topics are a **discovery hint**, not distribution. The README, examples, integrations, package and posts in
the right communities do more than tags. Do not add unrelated trending tags; it looks like spam and GitHub
may remove them.
