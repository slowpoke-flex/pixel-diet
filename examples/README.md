# Examples

Generated by `python examples/make_examples.py` and `python examples/shrink_demo.py`; no external data.

## Shrinking inputs

`shrink_demo.py` builds five deterministic stand-ins (a flat UI, a photo-wallpaper desktop, an A4 document,
a sprite with transparent padding, a camera frame), shrinks each with its preset and prints the measured
table used in the README. Outputs land in `examples/shrink/`, which is ignored by git.

```bash
python examples/shrink_demo.py
```

## Comparing outputs

| File | What it is |
|---|---|
| `a.png` | synthetic 256×256 gradient with a bright object |
| `b.png` | same scene with a new object and a local darkening |
| `mask_gt.png` / `mask_pred.png` | a binary mask and a deliberately incomplete prediction |
| `depth_gt.npy` / `depth_pred.npy` | a smooth depth field and a 2% scaled prediction |

Run:

```bash
python -m pip install -e .
pixel-diet diff examples/a.png examples/b.png --json report.json --sheet sheet.png
pixel-diet mask examples/mask_pred.png examples/mask_gt.png --classes 1
pixel-diet depth examples/depth_pred.npy examples/depth_gt.npy
```

Expected: the diff finds one large blob and one smaller darkening; the mask IoU is below 1; the depth
AbsRel is 0.02. The generated `report.json`, `sheet.png` and `diff.json` are ignored by git.
