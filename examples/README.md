# Examples

Generated by `python examples/make_examples.py`; no external data.

| File | What it is |
|---|---|
| `a.png` | synthetic 256×256 gradient with a bright object |
| `b.png` | same scene with a new object and a local darkening |
| `mask_gt.png` / `mask_pred.png` | a binary mask and a deliberately incomplete prediction |
| `depth_gt.npy` / `depth_pred.npy` | a smooth depth field and a 2% scaled prediction |

Run:

```bash
python -m pip install -e .
vision-eval diff examples/a.png examples/b.png --json report.json --sheet sheet.png
vision-eval mask examples/mask_pred.png examples/mask_gt.png --classes 1
vision-eval depth examples/depth_pred.npy examples/depth_gt.npy
```

Expected: the diff finds one large blob and one smaller darkening; the mask IoU is below 1; the depth
AbsRel is 0.02. The generated `report.json`, `sheet.png` and `diff.json` are ignored by git.
